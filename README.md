# OuO像素画社区

网页像素画编辑器 + 作品社区：有趣的作品，万里挑一。

## 站点信息

- 作者：纸片君ee、可爱的muse娘和deepseek娘
- 联系：paperee57@gmail.com、admin@paperee.guru
- 技术栈：前端原生 Canvas，后端 Node.js + Express，  
  数据库暂定 SQLite，字体为自托管的 Fusion Pixel。

## 站点特色

本站对比其他同类网站的特色。

1. 版本管理：每个作品都可以使用 1 个自动存档和 15 个手动存档。  
   若提示手动存档不够，你可以选择另存作品为副本，使用新的空存档，  
   也可以选择删除掉最旧的存档，再把进度保存到最后面的手动存档。

2. Z 快捷键：你可以在很多地方悬停鼠标后，长按键盘上的 Z 键  
   （在手机等无法使用鼠标的设备上则是长按）。用途包括但不限于：  
   对着小图使用，显示清晰的大图；对着作品使用，显示颜色与图层。

3. 悬停提示框：鼠标悬停在大多数按钮上时，会出现一个跟手的提示框。  
   尤其在绘画页中十分方便。提示框会告诉你工具的用途和键盘快捷键。

4. 站内生态：还没有关注作者的功能，但你可以给作者的作品点赞或评论，  
   让作者知道有人喜欢 ta 的作品 OuO。共同维护一个和谐有爱的社区~

5. 颜色与图层：你可以在作品页中，看到画作中的主要颜色与图层拆分  
   （不包含原始配色、图层透明度与叠加模式）。仅供学习和参考噢~

## 运行方式

### 本地运行

```bash
npm run dev      # 前后双服务：server 3001 + web 5173
npm run selftest -w server  # 后端自测
```

后端启动必须带 `--experimental-sqlite`（dev/start 脚本里已带）。

### 服务器运行

```bash
npm run lint     # 全仓检查
npm run build    # 前端构建
npm run start    # 启动构建产物
```
