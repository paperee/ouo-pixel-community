# OuO像素画社区

网页像素画编辑器 + 作品社区：打开就能画，画完就能发。

Beta版：实现了大部分预期的功能，BUG仍在测试中。

## 站点信息

- 作者：纸片君ee、可爱的muse娘和deepseek娘
- 联系：paperee57@gmail.com、admin@paperee.guru
- 技术栈：前端原生 Canvas，后端 Node.js + Express，数据库暂定 SQLite，缩略图缓存本地，字体为自托管的 Fusion Pixel

## 站点特色

本站对比其他同类网站的特色：

1. 版本管理——1 个自动存档加 15 个手动存档。手动存档满了的时候，你可以选择另存作品为副本，让手动存档重新开始计数，也可以选择直接删除最旧的存档再保存。
2. Z 快捷键——特别好用的快捷键，你可以在很多地方见到它，包括但不限于：对着小图使用，显示清晰的大图；对着作品使用，显示颜色与图层。
3. 悬停提示框——基本上，悬停在任何按钮上，都会出现一个跟手的提示框。尤其在画画页中，提示框内有工具的用途和快捷键。
4. 站内生态——虽然没有关注作者的功能，但你可以给作者的作品点赞或发表评论，让作者知道有人喜欢 ta 的作品 OuO。
5. 颜色与图层——你可以在作品页中，查看作品的肉眼配色与图层拆分（不包含原始配色、图层透明度与叠加模式）。

## 使用说明

有详细的悬停提示框在真是帮大忙了。悬停在任何按钮上都会出现跟手提示，画画页的提示框里还有工具用途和快捷键。

画画页快捷键（目前只放出了部分绘画工具的说明，持续更新中）：

- 左侧工具组：`B` 铅笔（可调笔头形状和大小）、`E` 橡皮（可调笔头形状和大小）、`G` 油漆桶（可调容差）、`I` 取色（在画布上右键像素也可以取色）
- 左侧选区组：`V` 选区（善用复制、剪切到新图层）、`Enter` 落定选区、`Delete` / `Backspace` 删除选区内像素、`Esc` 取消选区
- 左侧形状组：`L` 直线、`R` 矩形、`O` 椭圆、`F` 空心/实心切换
- 左侧笔刷组：`C` 方头/圆头切换，`[` + `]` 笔刷大小
- 左侧编辑组：`Ctrl` + `Z` 撤销，`Ctrl` + `Y` 重做
- 底部通用状态栏：`Ctrl` + `S` 保存草稿到手动存档，`+` / `-` 从中心点缩放画布，`Z` 按住看大图（社区作品、草稿箱、图层小图通用），`空格` 按住进抓手模式 + 左键拖画布平移

社区指南页（`#/guide`）内可左右翻页，也支持 `←` / `→` 方向键翻页。

## 运行方式

### 本地运行

```bash
npm run dev      # 前后双服务：server 3001 + web 5173
npm run selftest -w server  # 后端自测
```

后端启动必须带 `--experimental-sqlite`（dev/start 脚本里已带）。

### 服务器运行

```bash
npm run lint     # 全仓检查
npm run build    # 前端构建
npm run start    # 启动构建产物
```
